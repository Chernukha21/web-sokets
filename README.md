# Real-Time Chat

A simple real-time chat application built with React, Express, MongoDB, and Socket.IO.

## Features

* Create, edit, and delete messages in real time
* Join and leave separate chat rooms
* Room-specific message history
* Form validation and error handling
* Responsive dark UI

Available rooms:

* General
* Frontend
* Backend

## Tech Stack

* React
* Redux Toolkit
* Formik
* Node.js and Express
* Socket.IO
* MongoDB and Mongoose

## Running Locally

Install dependencies in both the client and server directories:

```bash
npm install
```

Make sure MongoDB is running, then start the server and client:

```bash for client
npm start 
```
```bash for server
npm run dev
```
The client runs on `http://localhost:3000` and the server on `http://localhost:5000`.
